# GDG Front-End Tasks

Weekly tasks and projects from the **GDG on Campus Canadian International College (CIC)** Front-End track. The track runs for about 6 months (20 sessions) and takes us from web fundamentals to building real React applications.

## About the Track

| Phase | Sessions | Focus |
|-------|----------|-------|
| 1. Web Foundations | 1-7 | HTML, CSS, Bootstrap, JavaScript, DOM, APIs, Git & GitHub |
| 2. Core React | 8-14 | JSX, components, React Router, Tailwind CSS, Hooks, forms, Axios |
| 3. React Application Skills | 15-18 | Context API, Zustand, TypeScript, TanStack Query |
| 4. Team Project | 19-20 | Planning, building, QA, deployment, and handoff |

## Session 1: HTML Website

A 3-page website built with plain HTML (no CSS):

- **Home (`home.html`)**: an image that links to the main page.
- **Main page (`main.html`)**: headings `h1` to `h6`, text formatting (bold, underline, italic, fonts, sizes, colors), nested lists, and a link back to the top of the page.
- **Contact Us (`contactus.html`)**: an image map linking each social media icon to its website in a new tab, a clickable image that opens an email to the site owner, and a copyright notice.

## Session 2: CSS Fundamentals

A responsive landing page for a student event ("Build Night"), built with HTML and CSS only:

- **Navbar and hero**: gradient backgrounds, a flexbox navigation bar, and a call-to-action button.
- **Schedule and speakers**: card layouts using Flexbox with `flex-wrap`.
- **Sidebar**: a "Good to know" card that sits beside the content on desktop and stacks below it on mobile.
- **Profile card**: a CSS Grid layout (image on the left, text on the right) that turns into a single centered column on phones.
- **Contact form**: styled inputs, labels, and a focus state.
- **Responsive design**: layout changes using Flexbox wrapping and a media query for small screens.


## Technologies

HTML5, CSS3, JavaScript, Bootstrap, Tailwind CSS, React, Git & GitHub (added as the track progresses).
